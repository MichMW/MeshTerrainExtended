# Mesh Terrain Extended

Fixes several issues with `MeshTerrainMode` in Epic's **Mesh Terrain** plugin.

> **Tested with:** Unreal Engine 5.8.4

## Setup

Use the pipelines from the plugin's content folder.

> [!NOTE]
> This is only needed for tessellation.

## Tips

To refresh shadows, run this command in the console:

​```
MeshTerrain.RefreshShadows
​```
